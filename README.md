# 🏫 Rate My Teacher - Congressional App Challenge 🚀

Welcome to the team repository for our K-12 Teacher Review Web App!

Our platform allows students, parents, and alumni to safely share feedback, ratings, and helpful tips about teachers. Our app is **100% anonymous**—we do not collect or store any personal data (no student or teacher names, emails, logins, or passwords). This keeps our project safe, private, and compliant with child privacy laws (COPPA).

---

## 🛠️ Step 1: Install Required Tools

Every team member needs to install these three free tools before writing or running code.

### 1. Python 3: The Brains
Python is the programming language that powers our server and communicates with our database.
* **Download:** Go to [python.org/downloads](https://www.python.org/downloads/) and click the yellow **"Download Python 3.xx"** button.
* **CRITICAL STEP FOR WINDOWS (Do not miss this!):**
  * Open the downloaded installer file.
  * Look at the very bottom of the installer window and check the box that says **"Add python.exe to PATH"**.
  * Click **Install Now**.
  *(If you forget this checkbox, your terminal will say "Python was not found"!)*
* **How to verify it worked:**
  * Open your terminal (`cmd` on Windows or `Terminal` on Mac).
  * Type: `python --version`
  * If it shows `Python 3.12.x` (or similar), you are ready!

### 2. Git: The Teleporter
