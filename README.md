# 🏫 Rate My Teacher - Congressional App Challenge 🚀

Welcome to the team repository for our K-12 Teacher Review Web App! This is our crowd-sourcing platform where students can safely share positive feedback, ratings, and helpful tips about their classes and teachers. 

This guide will help you set up your computer so you can run the app, explore our database, and start coding together! Follow the quests below to get ready.

---

## 🎮 Quest 1: Get the Tools 🛠️

We need three main tools on our computers to make this app work. Let's install them!

### 1. Python (The Brains 🧠)
We write our code in Python. 
* Go to [python.org/downloads](https://www.python.org/downloads/) and click the big yellow download button.
* **IMPORTANT (Don't miss this!):** When the installer opens, look at the very bottom and check the box that says **"Add python.exe to PATH"**. Then click "Install Now."

### 2. Git (The Teleporter 🌀)
Git helps us share our code on GitHub without overwriting each other's work.
* **Windows:** Download and install from [git-scm.com](https://git-scm.com/). (Just click "Next" on all default settings during install).
* **Mac:** Open your terminal and type `git --version`. If it asks you to install "Xcode Command Line Tools," click install!

### 3. DB Browser for SQLite (The Spyglass 🔍)
This free tool lets us visually look inside our database, like looking at an Excel spreadsheet.
* Download and install from [sqlitebrowser.org](https://sqlitebrowser.org/).
